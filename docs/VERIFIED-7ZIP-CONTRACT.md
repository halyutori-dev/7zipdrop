## 意図的に実装しないもの（非目標）

- `-sdel`（圧縮後に元ファイルを削除）: 不可逆。ドラッグ&ドロップ相手に既定で持たせるべきでない。
- ~~展開機能~~ → **v1.1 で追加**（利用者の明示的な要望）。既知の 7-Zip の RCE は信頼できない書庫の展開側に集中しているため、
  攻撃面が増えることを受け入れたうえで、契約 #26〜#30 にもとづく多層防御（entry パスの allowlist 検査・
  総展開サイズと空き容量の fail-closed 判定・展開後の symlink 脱出検査・空 staging への展開）を入れている。
  詳細は `docs/SECURITY.md`。
- 書庫の**削除・書き換え**: 展開しても元の書庫には一切触らない。展開先の既存ファイルも上書きしない。
- exe / dmg / iso / docx / apk などの自動展開: 7-Zip は開けるが、利用者が「書庫」と思っていないものを
  勝手に展開しない（明示的に「常に展開」モードを選んだ場合のみ 7-Zip に委ねる）。
- `._*`（AppleDouble）の除外: #10 のとおり `-spd` と両立しない。APFS/HFS+ 上では通常発生しないため literal 除外のみで運用する。

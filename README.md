# 7Zip Drop

ウインドウにドラッグ&ドロップしたものを、**あらかじめ決めた条件でそのまま圧縮 / 展開する**
macOS の GUI アプリです。書庫をドロップすれば展開、それ以外をドロップすれば圧縮します。
エンジンには公式の 7-Zip コンソール版 (`7zz` 26.02) を**同梱**しているため、Homebrew などの
事前インストールは不要です。

画面はドロップ領域だけです。右上の歯車ボタンを押すと、設定サイドバーが右からスライドインします。
設定は **General（共通）/ 7z / Zip** の 3 タブに分かれ、形式ごとに違う項目（圧縮率・パスワード・
分割サイズ）は各形式のタブに、共通の項目は General にあります。各項目名の横の **?** に
マウスを乗せると、その設定が実際に何をするかが出ます。

```bash
make app     # build/7Zip Drop.app を作る（release ビルド + ad-hoc 署名）
make run     # ビルドして起動
make install # /Applications にコピー
make test    # 全テスト（単体 + 実 7zz による end-to-end）
make audit   # セキュリティ / OSS ライセンス監査
make tips    # 設定行に OS のツールチップが実際に設置されているかを検査
make mutate  # テストスイートに検出力があるかを故意の欠陥注入で検査
```

## 圧縮と展開の切り替え

| モード | 挙動 |
|---|---|
| **自動判別**（既定） | ドロップされたものが**すべて書庫なら展開**、それ以外は圧縮。混在時は圧縮（書庫をまとめて包みたい場合があるため） |
| 常に圧縮 | 書庫をドロップしても圧縮（二重に包む） |
| 常に展開 | 自動判別の対象外の形式（`iso` / `exe` / `dmg` など）も 7-Zip に渡す |

自動展開の対象は `7z` `zip` `rar` `tar` `gz` `tgz` `bz2` `tbz2` `xz` `txz` `zst` `tzst` `lzma`
`cab` `arj` `lzh` `lha` `cpio` `wim` `z` と分割書庫の `.001`。
`docx` / `xlsx` / `apk` / `jar` / `exe` / `dmg` / `iso` は 7-Zip が開けても**自動では展開しません**
（利用者が「書庫」だと思っていないものを勝手に開かないため）。

## 設定（General）

| 項目 | 内容 |
|---|---|
| **形式** | 7z / zip — 圧縮するときに作る書庫の形式 |
| **保存先** | 元ファイルと同じ場所 / 指定フォルダ |
| **ドロップ処理判定** | 自動 / 圧縮 / 展開 |
| **完了時にFinderで表示 / 通知** | |
| **読み取れないファイルの処理** | スキップ / 処理中止（既定）|
| **シンボリックリンクの取り込み** | オン: リンクのまま保存 / オフ: リンク先の実体を取り込む |
| **メタデータ保存** | `.DS_Store` などを書庫に含めるか |
| **マルチスレッド処理** | |
| **処理後のファイル検証** | 作った書庫を読み直して確認 |
| **圧縮後に元のファイルを削除** | 既定オフ。**完全削除ではなく「ゴミ箱」へ移動**します |
| **展開後のサイズ制限** | 空欄なら上限なし（例: `10g`）。空き容量が足りない場合は常に中止 |
| **展開時の同名ファイルの上書き** | 既定オフ。オンでも置き換えた側は「ゴミ箱」へ移すので戻せます |
| **フォルダを作成して展開** | オン（既定）: 展開結果が必ずフォルダ 1 つになるようにします。書庫の中身が既にフォルダ 1 つならそれを使うので `Docs/Docs` にはなりません。ファイル 1 つ / 複数のときに書庫名のフォルダを作ります |
| **再帰的に展開** | `.tar.gz` の中の `.tar` まで続けて展開 |

## 設定（7z / Zip）

形式ごとに独立して保存されます。切り替えても、もう一方の設定は残ります。

| 項目 | 7z | Zip |
|---|---|---|
| **圧縮率** | 0 / 1 / 3 / 5 / 7 / 9 | 同じ |
| **ファイル名の暗号化** | ○ | — （zip は仕様上できません） |
| **パスワード** | しない / 都度質問 / 毎回共通 | 同じ |
| **分割サイズ** | `100m` など（1024 進） | ○ ※ |
| **実行されるコマンド** | 現在の設定で実際に走るコマンドを表示（パスワードはマスク） | 同じ |

※ **zip も分割できます**（`名前.zip.001`…）。7-Zip 方式の単純分割なので、他のツールで開くには
全パートを結合してください（`cat 名前.zip.0* > 名前.zip` で標準 zip になり、macOS の `unzip` でも開けます）。

### パスワードの扱い

- **しない**: 暗号化しません。
- **都度質問**: 圧縮を始める前に毎回ダイアログで入力します（確認入力あり）。
- **毎回共通**: 保存した 1 つのパスワードを常に使います。キーチェーンに保存され、
  `UserDefaults` や plist には一切書きません。
- **展開**: 暗号化書庫を展開しようとすると、設定に関係なく**ダイアログで入力**を求めます。
  「未入力」と「間違い」は区別して表示します。

zip は既定が ZipCrypto（実質破られる）なので、**常に AES-256 を強制**します。7z は AES-256 です。

## 提案として入れた機能

要件に加えて、実際に使うと必要になるものを入れています。理由も併記します。

| 機能 | なぜ入れたか |
|---|---|
| **既存ファイルを絶対に上書きしない** | `7zz a` は既存書庫があると**上書きせず黙って追記**して成功扱いで終わります（実測）。放置すると無関係なファイルが他人の書庫に混ざります。空き名（`名前 2.7z`）を選び、最終確定は `link(2)` のアトミックな名前取得で行います |
| **一時ディレクトリで作ってから移動** | 7zz は出力先へ直接書くため、強制終了すると保存先に壊れた書庫が残ります。0700 の作業ディレクトリで作り、成功時だけ移動します |
| **作成後の検証** (`7zz t`) | 作った書庫が本当に開けるかを確認します。ただし 7-Zip の検証コマンドはパスワードを標準入力から受け取れないため、暗号化書庫は**既定でスキップし「検証スキップ」と表示**します（黙って「検証済み」とは言いません） |
| **読めないファイルがあれば中止** (`-sse`) | 既定の 7-Zip は読めないファイルを**黙って除いた書庫**を作り「警告」で終わります。既定を fail-closed にしました |
| **シンボリックリンクはリンクとして保存** (`-snl`) | 既定の 7-Zip はリンク先の実体を取り込みます。`/etc/hosts` への symlink がフォルダに混じっていると、その中身まで書庫に入ります |
| **`.DS_Store` などを除外** | 配布用の書庫に macOS のゴミが入るのを防ぎます |
| **キュー + 進捗 + 中止** | 大きなファイルは時間がかかります。7zz の進捗出力を実バイト列から解析して表示し、中止は SIGTERM（7zz 自身が部分ファイルを消します） |
| **実行コマンドのプレビュー** | 何が起きるかを隠しません。パスワードは常にマスクされます |
| **Dock アイコンへのドロップ / 「このアプリで開く」** | ウインドウを開かずに使えます |
| **完了後に Finder で表示 / 通知** | 保存先が「指定フォルダ」のとき、どこに出たか分からなくなるのを防ぎます |
| **多スレッド切り替え** | バックグラウンドで走らせたいときに CPU を占有させない選択肢 |
| **展開: Zip Slip / 絶対パスの拒否** | 7-Zip 26.02 自身も無害化しますが、**exit 0 のまま黙ってパスを書き換える**ため、独立に検査して拒否します |
| **展開: zip bomb ガード** | 展開前に申告サイズを読み、上限と実際の空き容量（1 GiB の余裕込み）で止めます |
| **展開: symlink 脱出の事後検査** | リンク先は listing に出ないため、展開後に実ツリーを（リンクを辿らずに）走査し、外を指すリンクがあれば結果を破棄します |
| **分割書庫は `.002` を渡しても開ける** | 7zz は `.001` しか受け付けないため、こちらで読み替えます |

## 意図的に入れていないもの

- **7-Zip の `-sdel`（圧縮後に元ファイルを完全削除）**: 「圧縮後に元のファイルを削除」は実装しましたが、
  `-sdel` は使っていません。**ゴミ箱へ移動**するので取り消せます。書庫が問題なく作られたときだけ実行し、
  警告が出た場合（＝一部のファイルが書庫に入っていない可能性）は削除しません。
- **展開後に書庫を削除する機能**: 持ちません。
- **`exe` / `dmg` / `iso` / `docx` などの自動展開**: 7-Zip は開けますが、利用者が「書庫」と思っていない
  ものを勝手に開くのは驚きが大きく、parse する形式が増えるほど攻撃面も増えます。「常に展開」を
  選んだ場合のみ 7-Zip に委ねます。
- **`._*` の除外**: ワイルドカード解釈を無効化する `-spd`（下記）と両立しません。`-spd` の方が重要と判断しました。
  APFS / HFS+ 上では `._` ファイルは通常発生しません。

## 設計上の判断（実測にもとづく）

すべて `docs/VERIFIED-7ZIP-CONTRACT.md` に**実測の根拠つきで**記録しています。推測でオプションを
書かないための一次資料です。主なもの:

- **パスワードは `argv` に出さない**: `-p` を値なしで渡すと 7zz が実行時に聞いてくるので、標準入力で1行渡します。
  `ps` に出ません。
- **`-spd` を常時付ける**: これを付けないと、`report*.pdf` のような名前が**ワイルドカードとして展開され、
  意図しないファイルが書庫に混入**します。副作用として `-x` のパターン除外も無効になるので、除外はリテラル名のみです。
- **`--` を常時付ける**: `-rf.txt` のような名前がスイッチとして解釈されるのを防ぎます。
- **子プロセスの cwd を共通の親フォルダにして相対名で渡す**: 絶対パスで渡すと 7zz は basename に潰すため、
  異なるフォルダの同名ファイルを同時に渡すと `Duplicate filename on disk` で**致命的に失敗**します。
- **シェルを経由しない**: 引数ベクタで直接 exec します。ファイル名に `;` や `$(...)` があっても無意味です。
- **exit 1（警告）を成功として扱わない**: 警告は「一部のファイルが書庫に入っていない」ことを意味します。

## 動作要件

- macOS 14 以降（Apple Silicon / Intel — 同梱 7zz は universal binary）
- ビルドに Xcode（Swift 6.x）
